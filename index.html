RNA codes for proteins. But for a given protein, the number of RNA sequences coding for it grows exponentially with length. Such “synonymous” choices can differ dramatically in their structure and stability. This application samples stable coding sequences for a target amino-acid sequence and visualizes their likely structures, illustrating how fast algorithms can turn the huge design space into concrete RNA candidates. For background and example sequences, see the preprint.Warning: Costs grow quickly beyond a couple hundred amino acids. This browser build is single-thread CPU-WASM and does all computation on the visitor's machine.

1. sampleDraw RNAs compatible with the protein in the browser.
2. rankDeduplicate and keep the lowest-scoring candidates.
3. chooseInspect top RNAs in rank order.
4. visualizeRender sampled dot-bracket structures locally.
